===============================================================================
     GUÍA PASO A PASO PARA CONFIGURAR Y EJECUTAR SGTM (TRANSPORTE MONTENEGRO)
===============================================================================

Este documento contiene las instrucciones completas desde cero para instalar
las herramientas necesarias, configurar la base de datos y ejecutar el 
sistema de gestión de transporte (SGTM).

-------------------------------------------------------------------------------
1. PRERREQUISITOS PREVIOS
-------------------------------------------------------------------------------
Antes de comenzar, asegúrate de tener instalado en tu equipo:
- Python (Versión 3.10 o superior).
- PostgreSQL (Instalado y en ejecución en el puerto local 5432 o 5433).
- Git (opcional, para clonar el repositorio).

-------------------------------------------------------------------------------
2. INSTALACIÓN DE UV (GESTOR RÁPIDO DE PAQUETES Y ENTORNO)
-------------------------------------------------------------------------------
'uv' es una herramienta ultrarrápida para gestionar entornos virtuales y 
dependencias de Python sin conflictos.

Abre tu terminal/consola y ejecuta el comando según tu sistema operativo:

• En Windows (PowerShell como administrador o usuario normal):
  powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

• En macOS / Linux:
  curl -LsSf https://astral.sh/uv/install.sh | sh

• Verificación de la instalación:
  Cierra y vuelve a abrir tu terminal, luego verifica ejecutando:
  uv --version

-------------------------------------------------------------------------------
3. OBTENER EL PROYECTO Y NAVEGAR A LA CARPETA
-------------------------------------------------------------------------------
Navega a la carpeta del proyecto en tu terminal:

  cd sgtm

-------------------------------------------------------------------------------
4. MANEJO DE DEPENDENCIAS CON UV (SIN ERRORES)
-------------------------------------------------------------------------------
'uv' lee automáticamente los archivos `pyproject.toml` y `uv.lock` del proyecto 
para instalar exactamente las versiones requeridas de las librerías (Flet, 
SQLAlchemy, Psycopg3, ReportLab, etc.) dentro de un entorno virtual aislado (.venv).

1. Para crear el entorno e instalar todas las dependencias, ejecuta:
   uv sync

2. (Opcional) Activar el entorno virtual manualmente:
   - En Windows:
     .venv\Scripts\activate
   - En macOS / Linux:
     source .venv/bin/activate

Nota: No es estrictamente necesario activarlo manualmente si usas 'uv run' 
delante de tus comandos, ya que 'uv' usará automáticamente el entorno .venv.

-------------------------------------------------------------------------------
5. CONFIGURACIÓN DINÁMICA Y AUTOCREACIÓN DE LA BASE DE DATOS POSTGRESQL
-------------------------------------------------------------------------------
El sistema incluye una gestión de conexión robusta y dinámica a PostgreSQL:

1. Archivo de Configuración JSON (config_db.json):
   Al abrir la aplicación por primera vez, el sistema creará un archivo de 
   configuración en la carpeta Documentos del usuario:
   C:\Users\<NombreUsuario>\Documents\SGTM\config_db.json

   Contenido inicial del archivo:
   {
       "host": "localhost",
       "port": 5432,
       "user": "postgres",
       "password": "1234",
       "dbname": "transporte_montenegro"
   }

   * Si tu PostgreSQL en esa computadora usa otra contraseña, otro puerto (ej. 5433)
     o un usuario diferente, simplemente abre ese archivo con el Bloc de Notas,
     edita los valores deseados y guarda el archivo. La app se conectará de inmediato.

2. Autocreación de la Base de Datos:
   • ¡Ya no es necesario crear manualmente la base de datos en pgAdmin!
   • Si PostgreSQL está encendido y la base de datos 'transporte_montenegro'
     aún no existe, el sistema se conectará a PostgreSQL y ejecutará 
     automáticamente el comando `CREATE DATABASE "transporte_montenegro";` y 
     construirá todas las tablas del sistema.

3. Inicialización manual de tablas y usuario por defecto (Opcional):
   Si deseas construir explícitamente las tablas desde la terminal, ejecuta:
   uv run python src/database/setup_db.py

   Salida esperada en consola:
   ---------------------------------------------------------------------
   Iniciando la construccion completa de la base de datos...
   [OK] Exito! Todas las tablas y sus relaciones fueron creadas en PostgreSQL.
   [OK] Usuario administrador por defecto creado ('admin' / 'admin123').
   ---------------------------------------------------------------------

4. Acceso y Credenciales del Sistema:
   Al iniciar la aplicación, se mostrará la pantalla de Login:
   - Usuario: admin
   - Clave:   admin123

   * Se recomienda cambiar la contraseña inicial desde la pestaña 'Configuración'.

-------------------------------------------------------------------------------
6. EJECUCIÓN DEL PROGRAMA (SISTEMA DE GESTIÓN)
-------------------------------------------------------------------------------
• Para ejecutar en modo DESARROLLO (Escritorio):
  uv run flet run

• Para ejecutar en modo WEB (Navegador):
  uv run flet run --web

• Para ejecutar el archivo compilado listo (EJECUTABLE .EXE):
  Abre la carpeta:
  C:\Users\<NombreUsuario>\Documents\sgtm\dist\SGTM_Transporte\

  Y haz doble clic en el ejecutable:
  SGTM_Transporte.exe

-------------------------------------------------------------------------------
7. RESOLUCIÓN DE PROBLEMAS COMUNES
-------------------------------------------------------------------------------
• Error "psycopg.OperationalError: could not connect to server":
  - Verifica que el servicio de PostgreSQL esté en ejecución en tu equipo.
  - Abre el archivo `C:\Users\<Usuario>\Documents\SGTM\config_db.json` con el 
    Bloc de Notas y verifica que el host, puerto, usuario y contraseña coincidan.

• Error "password authentication failed for user 'postgres'":
  - Tu instalación local de PostgreSQL tiene una contraseña diferente a '1234'.
  - Edita la clave en `Documentos\SGTM\config_db.json` por tu clave real y guarda.

• Error de permisos al guardar PDFs o Backups:
  - Todas las copias de seguridad y comprobantes se guardan de forma segura en
    `C:\Users\<Usuario>\Documents\SGTM\`, evitando cualquier problema de permisos.
